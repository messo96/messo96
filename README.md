## 🚀 Featured Projects

### 🥏 Roundnet Smart Referee
**IoT · ESP32 · MQTT · React · Node.js**

An engineering thesis project exploring how embedded systems and infrared sensors could help detect faults during Roundnet matches.

- ESP32-based sensor system
- TCRT5000 infrared sensors
- MQTT communication
- Web dashboard concept for match monitoring

### 📦 RentUp
**Flutter · Mobile Development · Marketplace**

A peer-to-peer rental marketplace concept designed to make borrowing and renting everyday objects easier, safer, and more transparent.

- Rental listings and booking workflows
- Before-and-after rental photos
- Reviews and trust features
- A user-friendly cross-platform experience

### 💚 MatchDay
**Flutter · Firebase · Social Discovery**

A social discovery and dating app concept focused on compatibility, meaningful connections, and shared experiences.

- Compatibility-based matching
- Daily match discovery
- Profiles and user interactions
- Date planning and community feedback

### 🛒 CompraQuellaCosa
**Mobile Development · Smart Shopping**

An app concept designed to help people remember what they need to buy and make their shopping lists more useful.

- Personal shopping lists
- Product discovery ideas
- Nearby store suggestions
- A practical approach to everyday organization
